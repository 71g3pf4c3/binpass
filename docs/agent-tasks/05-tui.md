# Задание: TUI (M7)

> Вставь перед этим текстом `00-CONTEXT.md`.

## Цель

`binpass tui` на `charmbracelet/bubbletea` + `lipgloss`: поиск, дерево,
просмотр, OTP с обратным отсчётом (§5).

Уже готов `binpass menu` — одноразовый выбор через rofi/fzf/dmenu. TUI — другое:
полноценная сессия, в которой живут и работают.

## Что должно быть

* Дерево стора с навигацией и сворачиванием.
* Инкрементальный поиск (fuzzy), как в fzf.
* Просмотр записи с **замаскированным паролем** и переключением по клавише.
* OTP с живым обратным отсчётом до смены кода — используй `pkg/otp`
  (`Config.Expires` уже есть).
* Копирование в буфер (`pkg/clip`, восстановление прежнего содержимого само).
* Базовое редактирование: generate, rename, delete — с подтверждением.

## Требования, которые легко упустить

**Секреты не должны попадать в scrollback терминала.** Это главное отличие от
`show`. Пароль показывается только по явной команде и в alternate screen.

**Ленивая расшифровка.** Дерево строится из `store.List()` — ключ не нужен.
Расшифровывай только открытую запись. Если этого не сделать, при аппаратном
recipient (§3.3) навигация по стору превратится в череду касаний токена.

**Автоблокировка по бездействию.** Оставленный открытым TUI — открытый стор.

**Ресайз, узкие терминалы, отсутствие цвета** (`NO_COLOR`, `TERM=dumb`).

**Никогда не пиши секрет в лог или в файл состояния TUI.**

## Тесты

bubbletea тестируется через `teatest` — модель получает сообщения, проверяем
переходы состояний. Не требуй настоящего терминала.

Обязательно проверь:
* Открытие записи без identity → внятная ошибка, а не паника.
* Навигация по 2000 записей не тормозит и не расшифровывает лишнего.
* Пароль замаскирован по умолчанию.
* Таймер OTP не расходится с `pkg/otp`.

## Отдельно

`binpass history <name>` (§5) — все версии записи из git с diff по полям,
пароль замаскирован. Хорошо ложится в TUI как отдельный экран, но нужна и
CLI-команда. Зависит от git-транспорта из задания про sync — если его ещё нет,
сделай CLI-часть на прямом вызове `git log`, но изолируй, чтобы потом
переключить.
