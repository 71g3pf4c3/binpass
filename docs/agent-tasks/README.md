# Задания для агентов

Каждый файл — самостоятельное задание. **Перед текстом задания всегда вставляй
`00-CONTEXT.md`** — без него агент не знает правил проекта и сломает
совместимость с pass.

```
00-CONTEXT.md + 01-sync.md   →  агенту №1
00-CONTEXT.md + 02-tomb.md   →  агенту №2
...
```

## Что кому отдавать

| Файл | Что делает | Этап ТЗ | Статус | Можно параллельно? |
|---|---|---|---|---|
| `01-sync.md` | Синхронизация: движок, конфликты, git, облака | M3, M4 | — | да, но это критический путь |
| `02-tomb.md` | tomb/coffin, автозакрытие | M5 | — | да |
| `03-plugins.md` | Три уровня плагинов, capability-модель | M6 | — | да |
| `04-import-export-audit.md` | Импорт 9 форматов, HIBP-аудит, binary secrets | M2 | **✅ сделано** | — |
| `05-tui.md` | bubbletea TUI, history | M7 | — | да |
| `06-current-wip.md` | Незакоммиченный WIP: фиксы, e2e, completion, GitLab CI | — | частично (баги закоммичены) | **сначала** |
| `07-import-debt.md` | M2 debt: mock store, coverage gaps, bugs, improvements | M2 post | — | да, в любое время |

## Порядок

**`06-current-wip.md` отдавай первым.** Там незакоммиченные изменения в рабочем
дереве, включая два исправленных бага. Пока это не закоммичено, остальные
агенты будут работать поверх грязного дерева и конфликтовать.

Дальше:

* **`01-sync.md` — критический путь** (§14). Ошибка в модели данных означает
  переписывание, а не доработку. Дай его сильнейшему агенту и не торопи.
* Остальные аддитивны и хорошо идут параллельно.
* `04` **закрыт** (import, audit, binary). Документация обновлена.
* `07` — post-M2 debt. Можно забрать в любой момент.

## Зависимости между заданиями

* `05-tui.md` (команда `history`) хочет git-транспорт из `01-sync.md`.
  В задании описан временный обходной путь.
* `03-plugins.md` требует `--format=json` у всех команд. Сейчас он только у
  `ls`. Кто первый доберётся — тот и добавляет; остальным сказать.
* `02-tomb.md` и `01-sync.md` оба трогают `$XDG_DATA_HOME/binpass/` —
  пересечений по файлам нет, но договоритесь о структуре каталога.

## Что требовать в отчёте от каждого

1. Что сделано и что **сознательно не сделано** (с обоснованием).
2. Ответы на вопросы из §15, которые заданы в конце каждого файла.
3. Где ТЗ разошлось с реальностью и что предложено взамен.
4. Прогон полного набора: `make test`, `make cover`, `golangci-lint run`,
   оба Docker-образа. Скриншот/вывод, а не «всё зелёно».

Отчёт «сделано, тесты проходят» без деталей не принимать — по опыту, именно за
такими формулировками прячутся молча пропущенные тесты.
